# expert-panel — 专家团共识评审（ZCode 插件市场源）

本仓库本身就是一个 ZCode 插件市场：**添加本仓库为插件市场，即可一键安装「专家团共识评审」插件。**

> This repository is itself a ZCode plugin marketplace: add it as a marketplace source and install the **expert-panel** plugin in one click.

## 安装 / Install

ZCode → 插件市场 → 添加 → 添加插件市场 → 粘贴本仓库地址 → Personal → expert-panel-market → expert-panel → 安装（新会话生效）

> ZCode → Plugin Marketplace → Add → paste this repo URL → Personal → expert-panel-market → expert-panel → Install (takes effect in a new session)

装完试用 / Try it：`用专家团 quick 档评估：<你的问题>`

## 这是什么 / What it is

把重要决策交给多位不同视角专家：**独立作答 → 真匿名互评 → 仲裁归纳（共识率由脚本确定性计算，不足自动加辩）→ 主席综合 → 事实复核**，产出「稳定一致项 + 明示分歧」。零配置，默认全部角色用会话模型。
